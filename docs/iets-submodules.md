# iets and this flake's Git submodules

Verified against `iets` v0.2.0 (`a2cc10cc`) and this checkout (2026-10-31).

- **Git flake references do not include submodule contents.** `.?submodules=1#…` is rejected: root query parameters are unsupported ([parser](https://github.com/numtide/iets/blob/a2cc10ccbee132020aa4b1d89925112874f6322c/src/flake/mod.rs#L111-L126)). Without that flag, the Git snapshot skips index entries with mode `160000` ([snapshot](https://github.com/numtide/iets/blob/a2cc10ccbee132020aa4b1d89925112874f6322c/src/source/scm/git.rs#L342-L366)). Evaluating `.#nixosConfigurations.muadib.config.system.build.toplevel.drvPath` failed because the submodule's `modules/aspects/agents/pi/package.json` was missing from the virtual source.
- **An explicit `path:` ref does include initialized submodules.** It selects `SourceRef::Path` rather than the Git snapshot ([parser](https://github.com/numtide/iets/blob/a2cc10ccbee132020aa4b1d89925112874f6322c/src/flake/mod.rs#L180-L220)); the path source hashes the _entire_ directory without filtering ([path source](https://github.com/numtide/iets/blob/a2cc10ccbee132020aa4b1d89925112874f6322c/src/source/local.rs#L1-L10), [tree walk](https://github.com/numtide/iets/blob/a2cc10ccbee132020aa4b1d89925112874f6322c/src/source/local.rs#L82-L103)). `iets eval --raw 'path:/home/lucas/shinyflakes#nixosConfigurations.muadib.config.system.build.toplevel.drvPath'` succeeded, returning `/nix/store/qnn7mmv26dhbsinkzyn0sf6y3gl988j7-nixos-system-muadib-26.11.20261023.3ec6363.drv`.
- **This is not equivalent to the normal build.** Nix with `.?submodules=1` returned `/nix/store/35jl6r8zr5jiyp9ywwnp8clsswsgbc9y-nixos-system-muadib-26.11.20261023.3ec6363.drv`. The path source also includes `.git`, ignored and untracked files, not just Git-tracked files plus submodules. Uploading/building it can include private local data and churn derivation hashes on unrelated edits. No full build was attempted.
- `builtins.fetchGit { submodules = true; … }` is a separate case: for a local repo with `.gitmodules`, iets explicitly delegates to the real Nix fetcher ([source](https://github.com/numtide/iets/blob/a2cc10ccbee132020aa4b1d89925112874f6322c/src/builtins/fetch_git.rs#L182-L205), [fallback](https://github.com/numtide/iets/blob/a2cc10ccbee132020aa4b1d89925112874f6322c/src/builtins/fetch_git.rs#L288-L296)). This does not enable native `.?submodules=1` root evaluation.

## Test baseline for the isolated prototype

The unmerged `feat/submodule-root-fetch` branch in `/home/lucas/.btca/agent/sandbox/iets` passes all 13 flake end-to-end tests with its dev-shell Nix 2.34.9 (`nix develop --command cargo test --test e2e_flake`), including the new submodule test. Running the same suite with host Lix 2.95.4 passes 10/13; the three failures are in existing [Git working-tree](https://github.com/numtide/iets/blob/399f5710190af2f3c19eacfcd8ea5c621918fc6f/tests/e2e_flake.rs#L369), [sparse checkout](https://github.com/numtide/iets/blob/399f5710190af2f3c19eacfcd8ea5c621918fc6f/tests/e2e_flake.rs#L1520), and [symlink](https://github.com/numtide/iets/blob/399f5710190af2f3c19eacfcd8ea5c621918fc6f/tests/e2e_flake.rs#L1445) cases. Lix locks relative `path:` inputs with extra hash/mtime fields (leading iets's embedded [`call-flake.nix`](https://github.com/numtide/iets/blob/399f5710190af2f3c19eacfcd8ea5c621918fc6f/src/flake/call-flake.nix#L45) to lack `parent`), treats a sparse checkout's skipped file as clean where iets marks it dirty, and reports different symlink errors. This is a Nix-versus-Lix test baseline difference, not a failure of the added submodule path. No full system build was run.
