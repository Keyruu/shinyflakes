# Nix-on-Droid nixpkgs compatibility

- **The older package set is optional.** Upstream's [flake example](https://github.com/nix-community/nix-on-droid/blob/3264519d7df25f82e716e83607acf5e61f89b1ea/README.md#L183-L207) sets `nix-on-droid.inputs.nixpkgs.follows = "nixpkgs"` and passes `import nixpkgs { system = "aarch64-linux"; }` to `nixOnDroidConfiguration`. This repository now follows its own `nixos-unstable` input for both the Nix-on-Droid flake and the phone's packages (`flake.nix`, `modules/phone.nix`). The exact revision is pinned in `flake.lock` and only advances when that lock is updated.
- **Home Manager also has to follow the current input.** The bundled 2024 Home Manager's [gpg-agent options](https://github.com/nix-community/home-manager/blob/4de84265d7ec7634a69ba75028696d74de9a44a7/modules/services/gpg-agent.nix#L198-L203) access `pkgs.pinentry.flavors`, but current nixpkgs [removed `pkgs.pinentry`](https://github.com/NixOS/nixpkgs/blob/3ec636362e1816bc2f0888fa0fa2c69f1bc9e504/pkgs/top-level/aliases.nix). Pointing Nix-on-Droid's Home Manager input at the repository's current Home Manager avoids this mismatch (`flake.nix`); its phone activation-package path now evaluates successfully, though it emits SSH deprecation warnings.
- **The matching font is available.** Current nixpkgs [defines Maple Mono Normal NL NF](https://github.com/NixOS/nixpkgs/blob/3ec636362e1816bc2f0888fa0fa2c69f1bc9e504/pkgs/data/fonts/maple-font/default.nix); the locally installed x86_64 derivation contains `share/fonts/truetype/MapleMonoNormalNL-NF-Regular.ttf`. `modules/phone.nix` selects this file from the aarch64 derivation. The phone build and rendering still need on-device verification.
- **Host evaluation limit.** Upstream [hardcodes an Android proot store path](https://github.com/nix-community/nix-on-droid/blob/3264519d7df25f82e716e83607acf5e61f89b1ea/modules/environment/login/default.nix#L84-L98) and [documents its cache requirement](https://github.com/nix-community/nix-on-droid/blob/3264519d7df25f82e716e83607acf5e61f89b1ea/README.md#L153-L173). A full activation-package evaluation on this workstation needs impure evaluation **and** that Android proot path in the local Nix store; it currently stops at the missing path. This is not evidence the newer nixpkgs is incompatible on a bootstrapped phone.
