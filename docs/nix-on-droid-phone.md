# Phone terminal (Nix-on-Droid)

This uses the upstream Nix-on-Droid Android app, not a custom Android build. It is prototype-grade and primarily tested on ARM64. The flake output is `nixOnDroidConfigurations.default` and targets `aarch64-linux` only.

1. Install **Nix-on-Droid** (`com.termux.nix`) from F-Droid and finish its first-run bootstrap. Copy or clone this repository **with submodules** onto the phone (including `flake.lock`); use a trusted way to obtain the private submodules. The phone needs network access to the test workstation address.
2. From the repository directory on the phone, activate with `nix-on-droid switch --flake '.?submodules=1'`. **First-switch bootstrap:** if Git is missing, run `nix shell nixpkgs#git` first, then run the switch command inside that temporary shell. The bootstrap's flake-enabled setup provides the Nix command and the standard `nixpkgs` registry; after switching, this configuration installs Git declaratively. If the checkout on Android shared storage fails with `repository path ... is not owned by current user`, run `git config --global --add safe.directory /storage/emulated/0/Syncthing/shinyflakes` in Nix-on-Droid before retrying. For `?submodules=1`, also run `git config --global --add safe.directory /storage/emulated/0/Syncthing/shinyflakes/modules/aspects/agents` and `git config --global --add safe.directory /storage/emulated/0/Syncthing/shinyflakes/modules/aspects/private` before retrying. Only trust these directories if you control their synced contents; after the switch, Home Manager manages all three exceptions. Nix-on-Droid's `--flake` option defaults to `nixOnDroidConfigurations.default` and runs the impure evaluation needed by its activation package. Do not use the workstation's Home Manager generation on the phone. Open a new phone terminal session after switching to start Fish.
3. The activation writes a real `~/.termux/termux.properties` file in Android-visible home (not a `/nix/store` symlink) and configures Maple Mono Normal NL Nerd Font (the desktop variant) through Nix-on-Droid's `terminal.font` option. If an existing file is present, it is saved once as `termux.properties.bak`; later switches overwrite the managed file. To reload the buttons, close and reopen the Nix-on-Droid app after disconnecting any active remote terminal, or use the app's reload-style action if available. Check that the **DRAWER**, **sesh**, **prev**, **next**, **zoom** and **detach** buttons appear. This Android UI behavior still needs an on-device test.
4. Put an SSH private key on the phone **outside the Nix store**, authorize its public key on the workstation, and verify the server's host-key fingerprint independently on first connection. Run `ssh powder` (alias for `lucas@192.168.100.134:2222`); host-key verification remains enabled. On the workstation run `zellij list-sessions`, then `zellij attach <existing-session-name>`.

Fish is the phone's login shell, with a Starship prompt managed by Home Manager. In a new Fish session, run `storage` to enter `/storage/emulated/0`, or `rebuild` from anywhere to switch the checkout at `/storage/emulated/0/Syncthing/shinyflakes`. Zoxide remembers visited directories; after visiting the checkout, `z shinyflakes` jumps back to it. The first row opens the app sidebar with `DRAWER`, then sends `ALT s` (sessions), `ALT h`/`ALT l` (tabs), `CTRL SPACE z` (zoom) and `CTRL SPACE d` (detach). The other rows provide ESC, TAB, CTRL, ALT, ENTER, `/`, `-`, arrows and `KEYBOARD` (toggles the soft keyboard). Zoom and detach assume the workstation Zellij session is in its default locked mode; detach returns to the remote shell without stopping the session, which you can later reattach with `zellij attach <existing-session-name>`. Fullscreen changes to a shared tab can affect other clients. Sessions uses the workstation's existing Zellij binding, not a tool installed on the phone.

Mosh is installed **as a client only**. To use it later, the workstation must separately run `mosh-server` and allow the negotiated UDP ports (normally 60000–61000), in addition to SSH on port 2222. This configuration does not enable a server or open any firewall ports.
