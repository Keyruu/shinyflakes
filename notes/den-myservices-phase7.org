# Phase 7: =den.aspects.services.*= — service registry + collected facts

Splits the current ~nix/modules/services/my/{options,stack}.nix= into:
- **host-local option surface** (~options/my/services.nix~,
  ~options/my/stack.nix~) — for the wiring layer (vhosts, restic,
  quadlet, ...).
- **per-service den aspects** (~services/<name>.nix~) — one aspect
  per service. Each aspect writes into ~services.my.<name>~ inside
  its =nixos= block and emits cross-host quirks.
- **cross-host quirks** for =dashboard=, =monitor=, =scrape=,
  =public-proxy=, =oidc-config=. Collected via =pipe.collect=
  onto the *consuming* hosts (prime or mentat). Each quirk is
  either present or absent — no ~enable~ flag.

Replaces ~flake.allMyServices~ walks. Inspired by den's
[[https://github.com/denful/den/tree/main/templates/fleet-demo][fleet-demo]]
=backends= pipe. Quirk semantics per
[[https://den.denful.dev/explanation/quirks-and-pipes/][Quirks & Pipes]].

* Two layers (corrections from v1)

| Layer | Lives in | Consumer |
|---|---|---|
| Local (host-bound) | =services.my.<name>= options inside =nixos= block | the wiring modules in ~options/my/services.nix~ + ~options/my/stack.nix~ |
| Collected (cross-host) | quirks on the aspect (=dashboard=, =monitor=, =scrape=, =public-proxy=, =oidc-config=) | consumer aspects on prime (=dashboard=, =proxy=, =authelia=) and mentat (=prometheus=, =gatus=) |

Local config fields live on ~services.my.<name>~. The aspect has
**no flat fields** outside the =nixos= block — only the =nixos= block
+ quirks. Quirks may be config-thunks (~{ config, ... }:~) that read
from ~config.services.my.<name>~; or hardcoded values. Preference:
config-thunk for any value that exists on ~services.my.<name>=
(e.g. =domain=), hardcoded for service-specific metadata (e.g.
=dashboard.title=).

* Why quirks don't need an =enable=

A quirk is either emitted by the aspect or not. To opt out of the
dashboard, the aspect simply omits =dashboard = { ... }=. The consumer
sees an empty list for that quirk on that host. No boolean to keep
in sync.

* Quirks

| Quirk | Emitter | Consumer on | Provenance? | Source for hardcoded? |
|---|---|---|---|---|
| =dashboard= | every service (optional) | =den.aspects.prime.dashboard= | yes | ~title~, ~icon~, ~groups~, ~description~ |
| =monitor= | every service (optional) | =den.aspects.mentat.gatus= | yes | ~healthPath~, ~interval~, ~conditions~; ~url~ derived from =domain= |
| =scrape= | services with metrics | =den.aspects.mentat.prometheus= | yes | ~port~, ~metricsPath~, ~interval~, ~labels~ |
| =public-proxy= | services with public domain | =den.aspects.prime.proxy= | yes | ~domain~, ~cloudflare=; ~target~ derived from =source.host.addr= |
| =oidc-config= | OIDC-protecting services | =den.aspects.prime.authelia= | yes | ~clientId~, ~scopes~, ~redirectUri~, ~tokenEndpointAuthMethod=, ~claimsPolicy~ |

=oidc-config= carries the non-secret half. The secret
(~<clientId>ClientSecret~) stays in SOPS; prime's authelia consumer
reads it via =sops.placeholder.<clientId>ClientSecret=. Naming
convention: the quirk =clientId= is the SOPS key suffix.

* Service aspect — minimal example

Per-service lives at ~modules/aspects/services/<name>.nix~. The
service's *host* includes it via ~den.aspects.<host>.includes~.

#+BEGIN_SRC nix
# modules/aspects/services/immich.nix
{ den, ... }:
{
  den.aspects.services.immich = {
    nixos = { ... }: {
      # ── local option surface (consumed by options/my/services.nix
      #    and options/my/stack.nix)
      services.my.immich = {
        enable = true;
        description = "Photo library";  # for docs + dashboard card
        port = 2283;
        domain = "photos.peeraten.net";
        topology = "external";
        stack = { enable = true; directories = [ "data" "config" ]; ... };
        backup = { enable = true; paths = [ ... ]; };
        zfs = true;
        proxy = { server = "caddy"; cert = { host = "lab.keyruu.de"; }; };
      };

      # ── upstream service config (unchanged from today)
      services.immich.enable = true;
      virtualisation.quadlet.containers.immich = { ... };
    };

    # ── collected quirks (config-thunks reading from services.my.<name>)
    dashboard = { config, ... }: {
      title = "Immich";
      description = config.services.my.immich.description;
      icon = "https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/immich.svg";
      url = "https://${config.services.my.immich.domain}";
      groups = [ "family" ];
      newTab = true;
    };

    monitor = { config, ... }: {
      url = "https://${config.services.my.immich.domain}/api/server/ping";
      interval = "30s";
      conditions = [ "[STATUS] == 200" ];
    };

    scrape = { config, ... }: {
      port = 9090;
      metricsPath = "/metrics";
      interval = "15s";
    };

    public-proxy = { config, ... }: {
      domain = config.services.my.immich.domain;
      cloudflare = true;
    };

    oidc-config = { config, ... }: {
      clientId = "immich";
      scopes = [ "openid" "email" "profile" ];
      redirectUri = "https://${config.services.my.immich.domain}/api/oauth/redirect";
      tokenEndpointAuthMethod = "client_secret_post";
      claimsPolicy = "immich_email";  # declared in authelia
    };
  };
}
#+END_SRC

To opt out of a quirk, the aspect omits it. =services.my.immich=
without =dashboard= on the aspect = no dash card.

* Policy — collect all 5

#+BEGIN_SRC nix
# modules/aspects/policies/my-services-collect.nix
{ den, lib, ... }:
let inherit (den.lib.policy) pipe; in
{
  den.quirks.dashboard   = { description = "Service dashboard cards for prime's HTML UI"; };
  den.quirks.monitor     = { description = "Service health checks for mentat's gatus"; };
  den.quirks.scrape      = { description = "Service metrics endpoints for mentat's prometheus"; };
  den.quirks.public-proxy = { description = "Service reverse-proxy entries for prime's caddy"; };
  den.quirks.oidc-config = { description = "OIDC client config for prime's authelia"; };

  den.policies.collect-service-facts = { host, ... }: [
    (pipe.from "dashboard"   [ (pipe.collect ({ host, ... }: true)) pipe.withProvenance ])
    (pipe.from "monitor"     [ (pipe.collect ({ host, ... }: true)) pipe.withProvenance ])
    (pipe.from "scrape"      [ (pipe.collect ({ host, ... }: true)) pipe.withProvenance ])
    (pipe.from "public-proxy" [ (pipe.collect ({ host, ... }: true)) pipe.withProvenance ])
    (pipe.from "oidc-config" [ (pipe.collect ({ host, ... }: true)) pipe.withProvenance ])
  ];

  den.schema.host.includes = [ den.policies.collect-service-facts ];
}
#+END_SRC

* Consumer aspects

#+BEGIN_SRC nix
# modules/aspects/prime/dashboard.nix
{ den, lib, ... }:
{
  den.aspects.prime.dashboard = {
    nixos = { dashboard, config, ... }:
    let
      # dashboard = [{ value = { title, icon, url, ... }; source = { host = ...; }; }]
      cards = map (e: e.value) dashboard;
    in {
      # generate the custom HTML page from `cards`
      services.caddy.virtualHosts."dash.peeraten.net".root =
        "/var/www/dashboard";  # or a perSystem self.dashboard package
      # ... write the html from `cards` to a config file ...
    };
  };
}

# modules/aspects/prime/proxy.nix
{ den, lib, ... }:
{
  den.aspects.prime.proxy = {
    nixos = { public-proxy, config, ... }:
    let
      entries = lib.map (e: e.value // { hostIp = e.source.host.addr; }) public-proxy;
      byDomain = lib.groupBy (e: e.domain) entries;
    in {
      services.caddy.virtualHosts = lib.mapAttrs (_: es:
        let cfg = lib.head es; in {
          extraConfig = "reverse_proxy ${cfg.hostIp}:${toString cfg.port}";
        }
      ) byDomain;
    };
  };
}

# modules/aspects/mentat/prometheus.nix
{ den, lib, ... }:
{
  den.aspects.mentat.prometheus = {
    nixos = { scrape, lib, ... }:
    let
      # Group by service name; auto-derive job=service, instance=hostIp:port
      jobs = lib.map (e:
        let v = e.value; in {
          job_name = "${e.source.host.label}-${v.service or "default"}";
          targets = [ "${e.source.host.addr}:${toString v.port}" ];
          metricsPath = v.metricsPath;
          scrape_interval = v.interval or "15s";
        }
      ) scrape;
    in {
      services.prometheus.scrapeConfigs = jobs;
    };
  };
}

# modules/aspects/prime/authelia.nix
{ den, lib, ... }:
{
  den.aspects.prime.authelia = {
    nixos = { oidc-config, ... }:
    let
      clients = lib.map (e:
        let v = e.value; in {
          client_id = v.clientId;
          client_secret = "$secret";  # rendered via sops.template
          authorization_policy = "${v.clientId}_access";
          scopes = v.scopes;
          redirect_uris = [ v.redirectUri ];
          token_endpoint_auth_method = v.tokenEndpointAuthMethod;
        }
      ) oidc-config;
    in {
      # declare sops.template to inject client secrets
      sops.templates."authelia-clients.yml" = {
        content = builtins.toJSON { clients = clients; };
      };
      services.authelia.instances."main".configuration = {
        identity_providers.oidc.clients = clients;
      };
    };
  };
}
#+END_SRC

(Examples are sketches — the authelia wiring needs the SOPS secret
template to actually inject =client_secret = "<secret>"= per client.)
#+END_SRC

* Access control moves to people

=access.people= on the service is gone. The person declares which
services they can access:

#+BEGIN_SRC nix
# modules/people.nix (additive)
{
  den.people.lucas = {
    # ... existing fields ...
    services-access = [ "immich" "karakeep" "paperless" ];
  };

  den.people.simon = {
    services-access = [ "immich" ];  # only photo library
  };
}
#+END_SRC

The local nginx vhost generator (~options/my/services.nix~) reads
from ~people.<name>.services-access~ to build the IP allowlist:

#+BEGIN_SRC nix
# inside options/my/services.nix, when generating services.my.<name>.proxy vhost
filteredPeople = lib.filterAttrs (_: p: builtins.elem "immich" p.services-access) config.den.people;
allowlistIps = lib.concatLists (lib.mapAttrsToList (_: p:
  lib.mapAttrsToList (_: d: d.ip) p.devices
) filteredPeople);
#+END_SRC

* Backup — local-only

No quirk. Backup *registration* is host-specific (paths, units,
schedule). Visibility stays via the existing systemd timer monitors
on the backup host. Not a Phase 7 concern.

* Open questions / next steps

1. **dashboard HTML generator** — pure-Nix template, or call out to a
   per-system =self.dashboard= package? Pure-Nix is simpler, scales
   for ~20 services. Pick a path.
2. **scrape job naming** — =<host>-<service>= vs =<service>= (which
   breaks when same service runs on multiple hosts). Provenance gives
   the host info; per-host job name avoids scrape-target dedup.
3. **oidc-config quirk + SOPS secret binding** — declare the
   =sops.secrets.<clientId>ClientSecret= on the service host (does
   nothing there) AND on prime (where authelia reads it). Better:
   prime's authelia consumer declares the secret as a side effect of
   seeing the quirk. Decide before implementing.
4. **local proxy =whitelist.people=** — fully removed (people owns
   it), or kept as a fallback for explicit-allow cases? Recommend
   remove — explicit on people is sufficient.
5. **dashboard quirk =groups=** — authelia group names, not den
   people. Cross-check the names against the authelia seed file.
6. **stub one service first** — write ~modules/aspects/services/immich.nix~
   end-to-end, validate pattern, then batch-migrate the rest.
