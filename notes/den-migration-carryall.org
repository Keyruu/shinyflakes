* Decisions / open questions                                :questions:
:PROPERTIES:
:CUSTOM_ID: questions
:END:

- *Batteries*: keep all den imports in =modules/den.nix=, do NOT extract
  =modules/batteries.nix= (Lorenzo's split not adopted).
- *Role folders*: KEEP =aspects/{core,server,workstation,options}= and
  =apps/= and =stacks/=. Don't restructure to feature-named folders.
- *Dotted aspect names*: ADOPT going forward (folder-prefix style) for
  things under =modules/aspects/=. Apps namespace stays flat
  (=apps.X=) — namespace already wired in =modules/den.nix= via
  =(inputs.den.namespace "apps" false)=. Same for =stacks.X= when added.
  Pattern:
  - Aspects: =den.aspects.<folder>.<name>= (root-level)
  - Apps namespace: =apps.<name>= (namespace-level, no den.aspects prefix)
- *Multiple files → same aspect*: ADOPT (used heavily in carryall host,
  useful in apps later).
- *Freeform top-level attrs*: DEFER — see how it works once pipes/quirks
  arrive in Phase 5+.
- *User folder*: keep =modules/users/lucas.nix= flat (no subfolder).
- *Hardware-config*: no underscore prefix. Manual import in
  =default.nix= via =imports=.
